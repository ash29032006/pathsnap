How it works

What happens between choosing a trip and seeing its route.

  1. Request. This page sends only the trip ID to POST /predict.
  2. Candidates. The API projects GPS and road nodes to local metres and finds up to 10 road arcs within 60 m of each GPS point.
  3. Classifier. A tuned LightGBM model scores each (point, arc) pair from distance, heading, context and network features.
  4. HMM / Viterbi. Hidden states are the candidate arcs. Emissions come from the classifier, and transitions penalise the gap between driving distance on the network and straight-line GPS distance. Viterbi picks the most likely connected sequence.
  5. Scoring. Only after prediction does the API read its reference route, align it to the GPS points and compute accuracy. The reference route is never sent to this page.
